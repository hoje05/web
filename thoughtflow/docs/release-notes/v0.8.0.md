## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.8.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

## 새 기능: 정렬 버튼

왼쪽 도구 막대의 **정렬**을 누르면 흩어진 Box와 Route가 흐름 순서대로 보기 좋게 다시 놓입니다.

- 생각의 흐름대로 **왼쪽 → 오른쪽**. 이어진 Box끼리는 같은 높이에 맞춥니다.
- 갈래는 위아래로 고르게 벌어지고, 같은 열 안의 순서는 선이 덜 엇갈리게 고릅니다.
- Route는 오른쪽 면에서 나가 다음 Box의 왼쪽 면으로 들어갑니다. 여러 칸을 건너뛰거나 되돌아가는 Route는 Box 사이 빈 통로로 지나가 다른 Box를 가로지르지 않습니다.
- 선이 없는 Box는 맨 아래에 한 줄로 모읍니다.
- Box들은 새 자리로 부드럽게 움직이고, 다 보이지 않으면 화면도 함께 맞춥니다.
- `Ctrl+Z` 한 번(또는 알림의 **되돌리기**)이면 원래 모양과 손으로 그린 선까지 그대로 돌아옵니다.
- 이미 정렬된 보드에서 다시 누르면 아무것도 바뀌지 않습니다.
- 메뉴(`⋯` → 보기 → 정렬)에서도 쓸 수 있습니다. 새 단축키는 넣지 않았습니다.

## 다듬은 점

- 자동 연결선이 위아래로 멀리 떨어진 Box를 이을 때, 옆 Box 쪽으로 크게 휘어 넘어가지 않습니다.
- 한 면에 Route가 여럿 붙을 때 순서가 더 안정적입니다. 같은 방향으로 나가는 Route는 도착하는 곳의 순서를 따르므로 선이 덜 엇갈립니다.
