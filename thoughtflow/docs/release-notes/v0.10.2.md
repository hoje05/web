## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.10.2.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

## 바뀐 점

- **오른쪽 창(메모)이 열린 채로 시작해도 메모 칸이 보드와 거의 함께 뜹니다.** v0.10.1에서는 보드가 뜬 뒤 메모 칸이 0.3초쯤 늦게 나타났습니다.

v0.10.1에서 빨라진 시작(누르자마자 창 표시, 화면 코드 캐시, 가벼워진 본체, 마지막 보드 미리 읽기)은 그대로입니다.
Windows 테스트 PC에서 같은 큰 보드(300개 Box)로 잰 결과, 다시 켤 때 창이 뜨기까지 0.41초 → 0.30초, 보드가 그려지기까지 0.69초 → 0.52초입니다.
