## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.6.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다.

> Claude와 연결해 쓰고 있었다면, 설치 후 ThoughtFlow의 **✦ AI → Claude 데스크톱에 설치**를 한 번 더 눌러 Claude 쪽 확장도 업데이트하세요.

## 바뀐 점

- **Claude에게 “정리해줘”라고 하면 새 프로젝트에 정리합니다.** 텅 빈 새 보드를 만들고, 대화의 생각·행동·결과를 Box와 Route로 한 번에 그립니다. 다른 창을 보고 있었다면 작업 표시줄의 ThoughtFlow가 깜빡입니다.
- **새 프로젝트 = 텅 빈 새 보드가 바로 열림.** `+ 새 프로젝트`나 `Ctrl+N`을 누르면 이름을 묻지 않고 바로 열립니다. 이름은 위쪽 막대의 프로젝트 이름을 눌러 바꿉니다.
- **모든 저장은 이 PC 안에서만.** 프로젝트를 `C:\Users\<사용자 이름>\ThoughtFlow`에 저장합니다. OneDrive로 동기화되는 `문서` 폴더는 쓰지 않습니다. 예전 `문서\ThoughtFlow`의 프로젝트는 처음 실행할 때 자동으로 복사됩니다 (원본은 그대로 둠).

## 고친 문제

- Claude가 “ThoughtFlow가 응답하지 않는다(시간 초과)”라고 하던 문제
  - 원인: 파일 저장이 끝나지 않으면 새 프로젝트 만들기와 뒤이은 AI 요청이 모두 기다리기만 했습니다.
  - 이제 저장이 막히면 15초 안에 이유를 알려 주고, 다른 요청은 막히지 않습니다.
- 새 프로젝트 만들기가 되지 않던 문제 (같은 원인)
- 백신·동기화 프로그램이 파일을 잠깐 잡고 있을 때 저장이 실패하던 문제: 자동으로 다시 시도합니다.
- ThoughtFlow 창이 최소화되거나 가려져 있어도 AI 요청과 자동 저장이 늦춰지지 않습니다.
