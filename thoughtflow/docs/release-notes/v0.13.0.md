## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.13.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.
Claude 데스크톱 확장을 쓰고 있다면 AI 연결 창에서 확장을 다시 설치해 주세요 (새 도구가 들어 있습니다).

## 새 기능: Claude가 내 계획대로 진행 (워크플로우 4단계)

Claude에게 **"ThoughtFlow 계획대로 진행해줘"** 라고 말하거나 프롬프트 **계획대로 진행하기**를 고르면, Claude가 보드의 계획을 읽고 사람이 설계한 그대로 한 단계씩 진행합니다.

- **작업 지시서**: 단계를 시작하면 Claude는 그 단계의 할 일 · 완료 기준 · 만들 것 · 참고 자료 · 하지 말 것과, 쓸 도구를 **어떻게 쓰는지**까지 받습니다
  (스킬 → Skill 도구, 명령어 → 슬래시 명령, 커넥터 → 그 MCP 서버, 서브 에이전트 → Agent 도구). 앞 단계의 결과, 내가 되돌려 보낸 이유, 질문에 대한 내 답도 함께 갑니다.
- **순서 지키기**: 앞 단계가 끝나지 않았거나, 승인이 필요하거나, 사람이 하는 단계면 Claude가 시작할 수 없습니다. 왜 기다리는지도 Claude에게 알려 줍니다.
- **완료 검사**: 만들 것마다 만든 위치, 완료 기준마다 통과와 근거, 실제로 쓴 도구를 보고해야 완료됩니다. 하나라도 빠지거나 실패면 받아 주지 않습니다.
- **묻고 기다리기**: 계획에 없는 결정은 Claude가 질문하고, 오른쪽 창에서 답하면 이어서 진행합니다. 계획이 틀려 보이면 **수정 제안**만 남깁니다.
- **도구 확인**: Claude가 자기가 가진 스킬·명령어·커넥터·서브 에이전트를 알려 주면, 계획에 적었는데 없는 도구를 시작 전에 짚어 줍니다. 알려 준 도구는 도구 목록에도 함께 나옵니다.
- **계획은 사람만**: Claude는 보드 도구로 계획 블록을 고치거나 지울 수 없고, 계획 블록끼리의 Route(순서)도 바꿀 수 없습니다.
- Claude가 시작·질문·승인 요청·완료·실패·제안을 하면 화면 아래에 알림이 뜨고, 모두 `Ctrl+Z`로 되돌릴 수 있습니다.

지금은 Claude 데스크톱·웹 채팅에서 진행할 수 있고, 거기서는 스킬과 커넥터를 쓸 수 있습니다. 슬래시 명령어·서브 에이전트까지 쓰는 Claude Code 연결은 다음 버전(5단계)에서 추가됩니다.
