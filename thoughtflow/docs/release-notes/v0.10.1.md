## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.10.1.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

## 프로그램이 더 빨리 켜집니다

- **누르자마자 창이 뜹니다.** 화면이 다 준비될 때까지 숨겨 두지 않고, 창(프로그램 바 자리)을 먼저 보여 준 뒤 보드를 그립니다.
- **두 번째 실행부터 화면 코드를 다시 해석하지 않습니다.** 한 번 해석한 결과를 이 PC의 앱 데이터 폴더에 두고 다음 실행부터 바로 씁니다.
- **처음에 불러오는 화면 코드가 절반으로 줄었습니다.** 메모 편집기는 보드를 그린 뒤에 불러옵니다 (오른쪽 창을 처음 열 때도 기다리지 않도록 미리 불러 둡니다).
- **프로그램 본체가 1.6MB → 0.09MB로 가벼워졌습니다.** Claude·ChatGPT 연결 부품은 실제로 쓸 때(요청이 오거나 연결 점검을 할 때) 불러옵니다.
- **마지막 보드를 미리 읽습니다.** 창을 만드는 동안 마지막으로 쓰던 보드 파일을 읽어 두어, 화면이 뜨면 바로 그립니다.
- **맞춤법 검사를 껐습니다.** 한글 메모에는 쓰이지 않으면서 시작할 때 사전을 불러오거나 인터넷에서 받던 일을 하지 않습니다.

기능과 저장 방식은 그대로입니다. 처음 한 번은 준비하느라 조금 더 걸리고, 그다음부터 빨라집니다.
