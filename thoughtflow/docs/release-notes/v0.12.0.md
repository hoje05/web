## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.12.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

## 새 기능: 계획 블록의 도구를 목록에서 고르기 (워크플로우 3단계)

계획 블록의 **쓸 도구** 칸(스킬 · 명령어 · 커넥터 · 서브 에이전트)을 누르거나 몇 글자 치면, **이 PC에서 찾은 도구**가 설명과 함께 나옵니다.

- `↑` `↓` + `Enter` 또는 클릭으로 고릅니다. 설명으로도 찾을 수 있습니다 (예: "배포" → 배포 점검 스킬).
- 찾는 곳
  - 내 PC: `사용자 폴더\.claude`의 skills · commands · agents, 설치한 플러그인
  - 작업 폴더(계획 창에서 정함): 그 폴더의 `.claude\` 스킬·명령어·에이전트, `.mcp.json`
  - 커넥터: Claude Code 설정(`.claude.json`)과 Claude 데스크톱 설정의 MCP 서버
  - 기본 서브 에이전트: general-purpose · Explore · Plan
- 목록에 없는 이름도 적을 수 있습니다. 그런 이름은 **점선**으로 표시됩니다 (claude.ai 계정에 연결한 Gmail 같은 커넥터는 PC 파일에 없어서 목록에 나오지 않으므로 직접 적으면 됩니다).
- 계획 창에서 찾은 도구 개수를 보고, 스킬을 새로 설치했으면 **다시 찾기**를 누릅니다.
- 파일을 **읽기만** 하고 아무 곳에도 보내지 않습니다.

## 그 밖에
- 오른쪽 창이 좁을 때 계획 블록 칸이 옆으로 넘쳐 글자가 잘리던 문제를 고쳤습니다.
- 도구 이름을 고른 뒤 추천 목록이 계속 떠서 아래 칸을 가리던 문제를 고쳤습니다.
