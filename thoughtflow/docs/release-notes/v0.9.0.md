## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.9.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남고, 예전 프로젝트도 그대로 열립니다.

## 새 기능

### 1. 탭 줄을 끌어서 넘겨 보기
오른쪽 창 위쪽 탭이 많아 다 안 보일 때, 탭 줄의 **아무 곳이나**(탭 위, 탭 사이, 빈 곳) 왼쪽 버튼으로 누른 채 **좌우로 끌면** 탭 목록이 손가락으로 민 것처럼 따라 움직입니다.
- 살짝 눌렀다 떼면 원래대로 그 탭이 열리고, 끌었다 놓으면 아무 탭도 열리지 않습니다.
- 마우스 휠·트랙패드 가로 스크롤도 그대로입니다. 지금 보고 있는 탭은 굵은 글씨와 위쪽 줄로 표시됩니다.

### 2. Box에 사진과 자료 첨부
오른쪽 창의 **첨부** 줄에서 Box에 이미지와 파일을 붙입니다.
- 넣기: **+ 이미지·파일**(파일 고르기) · 오른쪽 창이나 보드의 Box 위로 **끌어다 놓기** · 이미지 **붙여 넣기**(Ctrl+V)
- 사진(PNG·JPG·WebP)은 작은 그림 + 크게 보기(← →), CSV는 표, JSON·TXT·Markdown은 글자로 바로 미리 보기, PDF 등은 PC의 기본 프로그램으로 열기
- 보드의 Box에는 그림 대신 이미지·파일 **개수만** 작게 표시
- 파일은 프로젝트 옆 **`프로젝트 이름.assets`** 폴더에 복사되어 이 PC 안에만 저장됩니다 (프로젝트 파일에는 위치와 정보만). 프로젝트 이름 바꾸기·휴지통·다른 이름으로 저장 때 함께 따라갑니다.

### 3. 태그
Box마다 태그를 여러 개 붙여 생각을 분류합니다.
- **+ 태그** → 이름 입력 → Enter: 태그가 붙고 저장된 태그에도 들어갑니다.
- 한 번 만든 태그는 **자동 완성**으로 다시 씁니다 (대소문자 무시, 앞부분 일치 먼저). `AI`·`ai`·`Ai`는 같은 태그입니다.
- 태그의 ×는 이 Box에서만 떼기. **저장된 태그 관리**(⋯ → 편집)에서 지운 태그는 이미 붙어 있던 Box에는 남고 추천에서만 빠지며, 같은 이름을 다시 쓰면 되살아납니다.
- 보드의 Box에는 태그 두 개와 `+N`만 작게 보입니다.

### 4. 정렬 버튼: → 나가는 흐름 / ← 들어오는 흐름 중심
정렬 버튼을 누를 때마다 방식이 바뀝니다 (버튼의 화살표가 다음에 할 정렬).
- **정렬 →** (첫 번째): 지금까지의 정렬 그대로 — 흐름 순서대로 왼쪽 → 오른쪽.
- **정렬 ←** (두 번째): **고른 Box로 들어오는 흐름을 중심**으로. Route를 거꾸로 따라가며 그 Box로 들어온 생각들이 바로 앞에 모이고, 그 앞의 생각은 더 왼쪽에 놓입니다. Box를 고르지 않았으면 흐름이 가장 많이 모이는 마지막 Box가 중심입니다.
- 순환이 있어도 안전하고, 바꾸는 것은 **위치와 선 모양뿐**입니다 (선의 방향·연결, 글, 태그, 첨부는 그대로). `Ctrl+Z` 한 번이면 정렬 전으로.

## 그 밖에
- 사진 붙여 넣기·태그 붙이기 같은 변경도 모두 `Ctrl+Z` / `Ctrl+Y` 로 되돌리고 다시 할 수 있습니다. 메모를 쓰는 중에 붙여 넣어도 되돌리는 순서가 맞습니다.
- Claude·ChatGPT가 Box를 읽을 때 태그와 첨부 목록도 함께 봅니다 (첨부 파일 내용은 PC 밖으로 보내지 않습니다).
- 프로젝트 파일 형식이 버전 3이 되었습니다. 예전 파일은 그대로 열리고, 저장하면 새 형식으로 바뀝니다.
- 새 단축키는 넣지 않았습니다 (기존 단축키와 겹치지 않게).
