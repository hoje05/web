## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.11.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

> 이번 버전부터 프로젝트 파일 형식이 v4가 됩니다. 예전 프로젝트는 그대로 열리지만, 저장한 뒤에는 v0.10 이하에서 열 수 없습니다.

## 새 기능: 계획 (워크플로우) — 1부

보드를 **계획표**로 씁니다. 목표는 "내가 적고 설계한 계획대로 Claude가 만들어 내게 하기"이고, 이번 버전은 계획을 **쓰고 보는** 부분입니다.
Claude가 계획을 읽고 단계대로 진행하는 연결은 다음 버전에서 추가됩니다.

- **계획 블록**: Box를 계획 블록으로 만들면 단계마다 정할 수 있습니다.
  - 할 일, **완료 기준**(체크리스트), **만들 것**(경로 + 조건), 참고 자료
  - Claude가 할지 사람이 할지, **시작 전 승인**, **검토 후 다음으로**
  - **쓸 도구**: 스킬 · 명령어 · 커넥터 · 서브 에이전트(종류·모델·지시) · 하지 말 것
- **순서**: 계획 블록끼리 이은 Route = 순서. 앞 단계가 끝나야 다음 단계를 시작할 수 있습니다.
- **보드에 상태 표시**: 시작 가능 · 진행 중 · 승인 대기 · 질문 중 · 검토 대기 · 완료 · 실패 · 막힘, 정한 도구 개수
- **사람이 하는 일**: 승인, 질문에 답하기, 검토 통과 / 다시 하기, 상태 직접 바꾸기
- **계획 대비 결과**: 만들 것 ↔ 만든 위치, 완료 기준 ✓/✗와 근거, 지정한 도구 ↔ 실제로 쓴 도구(다르면 ⚠)
- **계획 창** (프로그램 바의 계획 버튼): 전체 목표, 작업 폴더, 기본 도구, Claude 권한, **계획 잠그기**, 동시 진행 수, 단계 목록, **계획 점검**, Claude의 수정 제안
- 계획은 사람만 고칩니다. 모든 변경은 `Ctrl+Z`로 되돌릴 수 있습니다. 새 단축키는 없습니다.
