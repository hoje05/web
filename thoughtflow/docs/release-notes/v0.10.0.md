## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.10.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.
설치한 뒤 **✦ AI → Claude 데스크톱에 설치**를 한 번 더 눌러 Claude 쪽 확장도 새 버전으로 바꿔 주세요.

## 새 기능

### 1. Claude 연결 점검 · 고치기
Claude에 ThoughtFlow가 연결되지 않을 때 원인을 찾아 줍니다. **✦ AI → 연결 점검**
- ThoughtFlow가 **Claude가 쓰는 것과 같은 연결 프로그램을 직접 실행**해 보고, 도구 목록을 받아 오는지까지 확인합니다.
- Claude 데스크톱 설치 여부, ThoughtFlow 확장이 **꺼져 있거나 옛 버전**인지, Claude 설정 파일의 등록이 **없는 프로그램을 가리키는지**(ThoughtFlow를 옮기거나 다시 설치한 경우), Claude 로그에 남은 ThoughtFlow 오류를 보여 줍니다.
- **설정 파일에 직접 등록**: 확장 설치 창이 뜨지 않거나 설치해도 안 될 때, Claude 설정 파일(`claude_desktop_config.json`)에 ThoughtFlow를 바로 넣습니다. 원래 파일은 백업하고 다른 설정은 그대로 둡니다. Node.js 설치는 필요 없습니다.
  등록한 뒤에는 Claude를 **완전히 종료**(트레이의 Claude 아이콘 → 종료)하고 다시 켜세요.
- **점검 결과 복사**: 그래도 안 되면 이 글을 보내 주세요. 비밀 주소와 토큰은 가려서 복사됩니다.

### 2. ChatGPT 플러그인 · Claude 웹/휴대폰 연결 (고정 주소)
ChatGPT의 새 **플러그인** 화면(chatgpt.com/plugins → 추가 → 사용자 지정 MCP 서버 추가)과 Claude 웹·휴대폰의 **커넥터**로 ThoughtFlow를 쓸 수 있습니다.
- **고정 주소 (ngrok 무료 계정)**: 인증 토큰을 한 번 넣으면 ThoughtFlow를 다시 켜도 주소가 그대로라, ChatGPT에 주소를 다시 넣을 필요가 없습니다. 토큰은 이 PC 안에 암호화해 저장합니다.
- **임시 주소 (Cloudflare, 가입 없음)**: 예전처럼 켤 때마다 주소가 바뀝니다. 바뀌면 “주소가 바뀌었습니다”로 알려 줍니다.
- 주소를 만드는 프로그램(cloudflared · ngrok)이 없으면 **자동으로 받기** 한 번으로 준비됩니다.
- 틀린 토큰, 다른 곳에서 이미 쓰는 주소 같은 문제는 알기 쉬운 말로 알려 줍니다.

### 3. 메모 안에 그림 · 그래프
오른쪽 창의 메모(글쓰기 칸) 안, 글 사이에 그림과 그래프를 넣습니다.
- **그림**: 메모를 쓰다가 **붙여 넣기**(Ctrl+V) · 메모 칸에 **끌어다 놓기** · `/그림`. 그림 위의 **S · M · L**로 크기, 두 번 누르면 크게 보기(← →로 메모 안의 다른 그림).
- **그래프**: `/그래프` → 자료 칸에 표를 적으면 바로 **막대 · 꺾은선 · 원** 그래프가 그려집니다. 마우스를 올리면 값, **표로 보기**로 숫자 확인. 엑셀에서 복사한 표도 됩니다.
  ```
  type: line
  title: 청크 크기별 정확도
  unit: %
  청크, 정확도, 재현율
  256, 71, 66
  512, 78, 75
  ```
- Claude·ChatGPT에게 “이 결과를 그래프로 메모에 넣어줘”라고 하면 AI가 같은 형식으로 그래프를 넣습니다.
- 메모 파일에는 Markdown 글(`![설명](assets/…)`, ` ```chart ` 블록)로 저장되고, 그림 파일은 첨부와 같은 `프로젝트 이름.assets` 폴더에 복사되어 이 PC 안에만 있습니다.
- 넣기·크기 바꾸기·그래프 자료 고치기 모두 `Ctrl+Z` / `Ctrl+Y`로 되돌립니다.

## 그 밖에
- 메모가 그림·그래프로 끝나도 맨 끝(Ctrl+End)이나 그 아래를 눌러 이어 쓸 수 있습니다.
- 메모 칸에 그림이 아닌 파일(CSV·PDF …)을 놓으면 Box의 첨부로 들어갑니다.
- 새 단축키는 넣지 않았습니다 (기존 단축키와 겹치지 않게).
