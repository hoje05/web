## 설치

아래 **Assets**의 `ThoughtFlow-Setup-0.7.0.exe`를 받아 실행하세요 (Windows 10/11, 64비트).
파란 창 “Windows의 PC 보호”가 뜨면 **추가 정보 → 실행**을 누르면 됩니다. 만들어 둔 프로젝트는 그대로 남습니다.

> Claude와 연결해 쓰고 있다면, 설치 후 **✦ AI → Claude 데스크톱에 설치**를 한 번 더 눌러 주세요. Claude가 메모에 제목·목록·할 일을 쓸 수 있게 됩니다.

## 새 기능: 메모를 Notion처럼

오른쪽 창의 메모가 **블록 편집기**가 되었습니다. 한 줄이 한 블록입니다.

- **`/` 메뉴**: 텍스트 · 제목 1~3 · 글머리 목록 · 번호 목록 · 할 일 목록 · 인용 · 코드 · 구분선
- **바로 입력**: `# ` 제목, `- ` 목록, `1. ` 번호, `[] ` 할 일(체크박스), `> ` 인용, `---` 구분선, `**굵게**`
- 글자를 고르면 **서식 막대** (굵게 · 기울임 · 취소선 · 코드)
- Markdown 글을 붙여 넣으면 목록·제목으로 바뀌고, 복사하면 Markdown 글로 복사됩니다.
- 메모는 파일에 Markdown 글자로 저장됩니다. 예전 메모도 그대로 열립니다.

## 단축키

기존 단축키와 겹치는 편집기 단축키는 넣지 않았습니다. 메모를 쓰는 중에도 기존 단축키는 전과 똑같이 동작합니다.

- `Ctrl+S` 저장
- `Ctrl+Shift+S` 다른 이름으로 저장
- `Ctrl+F` 찾기
- `Ctrl+=`/`-`/`0` 확대·축소
- `Ctrl+Z` 입력 되돌리기
- `Esc` 나가기
- `Tab` 다음 칸

새로 쓸 수 있는 편집기 단축키는 다음과 같습니다.

- `Ctrl+B` 굵게, `Ctrl+I` 기울임, `Ctrl+E` 코드
- `Ctrl+Alt+1~3` 제목
- `Ctrl+Shift+8/7/9` 글머리·번호·할 일 목록
- `Ctrl+Shift+B` 인용
